The 8 lines that answer 90% of Grid questions
1display: grid goes on the container; direct children become grid items.
2Flexbox = one dimension. Grid = rows and columns together. Real sites nest both.
3grid-template-columns / -rows draw the map; item placement gives boxes addresses.
4fr is a ratio of available space, not a pixel size. Fixed tracks and gaps are removed first.
5A grid with n tracks has n + 1 lines. Count lines, not boxes.
6Line numbers answer where; span answers how many tracks.
7grid-area = row-start / column-start / row-end / column-end.
8Debug size first: Grid is greedy sideways, shy downwards. 1fr of no height is no height.

CTurning Grid on - tracks, fr, gap

.container {
  display: grid;
  grid-template-columns: 1fr 2fr;
  grid-template-rows: 1fr 1fr;
  gap: 10px;
}
  • One space-separated value = one track.
  • 1fr 2fr makes two columns in a 1:2 ratio.
  • gap spaces rows and columns; it is the same property from Flexbox.
  • Grid items stretch to fill their cell on both axes by default.
1fr2fr
fr is ratio thinkingIn a 600px container with no gap, 1fr 2fr becomes 200px + 400px. Same mental model as flex:1 and flex:2.
Grid infers rowsDeclare 8 columns and add 64 items: Grid fills items 1-8, then creates an implicit row for 9-16, and continues.

GRID SIZING - choose each track's behaviour Fixed - auto - fr - minmax() - repeat() - then test the layout by resizing and changing content.

Gauto - same word, different axis

grid-template-columns: 200px auto;
/* auto column eats leftover WIDTH */

grid-template-rows: 100px auto;
/* auto row fits its CONTENT height */
200pxauto - leftover
The lesson's main trapAuto column stretches; auto row just fits. This is the same width-greedy / height-shy asymmetry as the blank chessboard, now behind an explicit keyword.

An auto row grows from one text line to a full paragraph, but it does not stretch merely because the viewport is tall.

Hfr, minmax(), and repeat()

fr is a live ratio 1fr 2fr protects 1:2. Add lots of content to row 2 and row 1 may also grow, even when row 1's content never changed.
minmax(min,max) Grid's one-function version of Flexbox's min-width + max-width: grow to the ceiling, shrink to the floor, never cross either.
repeat(count,value) Works for any value: repeat(8,1fr), repeat(2,200px), or repeated minmax() tracks.

GRID PLACEMENT - give every item an address The template draws the map. Lines, spans, shorthands, and areas choose the occupied rectangle.

LTracks vs lines - count the borders

1column 12column 23column 34

Three columns create four vertical lines. An item covering columns 1 and 2 uses grid-column: 1 / 3.

SyntaxRead it as
2 / 5start at line 2, stop at line 5
5 / 2same area, reverse numeric direction
-3 / -1final two tracks from the far edge
2 / span 3start line 2, occupy 3 tracks
Where vs how manyLine numbers answer where. span answers how many. span is a positive track count; negative numbers are for line addresses from the far edge.

PAuto-placement, order, and overlap

order changes the visual queue

Accessibility warningVisual order does not change DOM reading order or keyboard focus order. Keep meaningful content order correct in the HTML.

Explicit items may overlap

.a { grid-area: 1 / 1 / 3 / 3; }
.b {
  grid-area: 2 / 2 / 4 / 4;
  z-index: 2;
}

Grid allows both claims. Source/paint order and z-index decide the visible layer.

QGrid outside, Flexbox inside

.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1.5fr;
  grid-template-rows: 1fr 1fr;
}
.item {
  display: flex;
  justify-content: center;
  align-items: center;
}
Different layers, different jobsGrid decides the emoji boxes' rows, columns, and spans. Flexbox centers one emoji inside each box. Neither tool replaces the other.

MONDRIAN PROJECT - design to Grid Capstone: fixed track geometry - black gaps - spans/areas - colour ownership - Flexbox centering.

WFrame geometry and the black-line trick

.container {
  width: 748px; height: 748px;
  display: grid;
  background: #000;
  grid-template-columns:
    320px 198px 153px 50px;
  grid-template-rows:
    414px 130px 155px 22px;
  gap: 9px;
}

Width: 320 + 198 + 153 + 50 + (3 x 9) = 748.
Height: 414 + 130 + 155 + 22 + (3 x 9) = 748.

Why gaps become black linesGrid lines are coordinates, not paintable objects. gap is transparent, so the black container background shows between the coloured items.
