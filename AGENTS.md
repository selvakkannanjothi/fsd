# fsd

This repository holds notes, transcripts, and code for a full stack web development learning journey.

## Goal

I want to learn full stack development — covering frontend, backend, databases, and deployment — from the ground up.

## Structure

- `course_content/` — raw lesson transcripts, organized by topic (e.g. `Introduction/`). Source material, not to be edited.
- `my_notes/` — my own study notes distilled from `course_content/`, mirroring the same topic folders (e.g. `Introduction/`).
- `tasks/` — practice tasks/exercises for each lesson, mirroring the same topic folders (e.g. `Introduction/`).

## Working with AI coding assistants here

- When explaining concepts, assume I'm learning — favor clear explanations over terse answers, and connect new topics back to ones already covered in `course_content/`.
- When writing code for exercises, prefer well-commented, beginner-friendly examples over clever/compact code.
- When asked to create notes for a lesson in `course_content/<topic>/`, write them to `my_notes/<topic>/`, not alongside the source transcript.
- When asked to create practice tasks for a lesson in `course_content/<topic>/`, write them to `tasks/<topic>/`, matching the same topic folder name.
